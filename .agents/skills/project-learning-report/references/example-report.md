# 路径简化为什么要看最小净空

这是一个可以手算的教学示例。地图、数据和代码均为示意，方便演练如何从一个现象读到一个判断。

## 一条捷径为什么被拒绝

假设平台需要穿过一个窄通道。规划器先得到一条折线路径，后处理试着把两段折线换成一条直线。直线更短，但会擦着拐角走。这里的**净空**是参考路线到禁区边界的最短距离，单位为米。它反映的是计划路线留出的空间。

## 代码在哪里做决定

路径简化提出一条候选捷径，净空检查比较候选净空和所需下限，然后返回是否接受。这个示例的规则是，原路线至少达到目标净空时，就用目标值作下限。原路线已经低于目标时，允许保持原来的净空水平。

```python
def keeps_clearance(old_m, candidate_m, target_m):
    required_m = min(old_m, target_m)
    return candidate_m >= required_m
```

`old_m` 是原路线最小净空，`candidate_m` 是候选捷径最小净空，`target_m` 是期望保留的净空。三个输入的单位都是米。返回 `True` 表示这条候选捷径通过净空检查。

## 把数值代进去

| 条件 | 原路线 | 候选捷径 | 需要保留 | 判断 |
| --- | ---: | ---: | ---: | --- |
| 目标净空为 0.10 米 | 0.50 米 | 0.03 米 | 0.10 米 | 拒绝 |
| 目标净空为 0.10 米 | 0.08 米 | 0.08 米 | 0.08 米 | 通过 |

第一行中，候选捷径少留了 0.07 米，所以净空检查拒绝它。第二行展示了原路线已低于目标值时的判断。这里仅演示对参考线的检查，实际跟踪轨迹的最小净空仍需测量。

## 自己核对一次

保持第二行的原路线和目标值，把候选捷径的净空改成 `0.07` 米。先算 `required_m`，再判断 `keeps_clearance(0.08, 0.07, 0.10)` 的返回值。

算出下限是 `0.08` 米、函数返回 `False`，就完成了练习。可以把函数和 `assert not keeps_clearance(0.08, 0.07, 0.10)` 放进同一个 Python 文件运行核对。
